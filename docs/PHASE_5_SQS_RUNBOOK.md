## Cost and limits

[AWS SQS pricing](https://aws.amazon.com/sqs/pricing/) has no standing queue fee and includes one million requests per month across customers; sends, receives (including empty long polls), deletes and visibility changes count. SSE-SQS adds no KMS-key fee. A handful of manually run tasks can be within the request allowance, but actual charges depend on total account use and credits. Each 1-vCPU/2-GB Fargate task costs roughly $0.049/hour at the existing us-east-1 planning rates, plus temporary public IPv4, Aurora wake/compute, CloudWatch logs and ECR storage. Four five-minute tasks would be roughly $0.02 for Fargate CPU/memory before those other items; that is an estimate, not a hard cap or measured bill. Idle SQS queues do not run compute, while stored messages expire under four/seven-day retention. No automatic paid LLM/search requests, scheduled pipeline or always-running service is present.
